## ✨ Fitur Utama

| Fitur | Deskripsi |
|-------|-----------|
| 📊 **Dashboard Real-time** | Lihat statistik tugas secara langsung dengan visual yang menarik |
| ➕ **CRUD Tugas** | Tambah, edit, dan hapus tugas dengan mudah |
| 🎯 **Manajemen Status** | Ubah status tugas dari belum dikerjakan → sedang dikerjakan → selesai |
| 📅 **Sorting by Deadline** | Tugas otomatis terurut berdasarkan deadline |
| 🔍 **Pencarian & Filter** | Cari dan filter tugas berdasarkan status |
| 📱 **Responsive Design** | Optimal di mobile, tablet, dan desktop |
| ⚡ **Performance** | Interface yang cepat dan responsif |
